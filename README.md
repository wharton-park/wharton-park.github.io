# Wharton Park Coffee Bar

The public digital menu for the Wharton Park Coffee Bar.

**Live site:** https://wharton-park.github.io/

## Site files

- `index.html` — responsive menu interface
- `recipes.json` — 46 drink recipes and Approved metadata
- `.nojekyll` — serves the static files directly with GitHub Pages

## Publishing

GitHub Pages should publish from the `main` branch, root folder (`/`).

Good drinks. Good company. Right at home.
